## Objective

To develop computer vision systems capable of performing object detection and image segmentation using deep learning techniques.

## Dataset Used

* **COCO (Common Objects in Context) Dataset** for object detection.
* A suitable image dataset for semantic segmentation, depending on the segmentation implementation.

## Tools and Technologies

* Python
* Google Colab
* Ultralytics
* YOLO11n
* YOLO segmentation model (for the segmentation part)

## Implementation

1. Installed and imported the required libraries.
2. Loaded the YOLO11n object detection model.
3. Evaluated the model using the COCO validation dataset.
4. Detected and localized objects using bounding boxes.
5. Generated and saved the detection results.
6. Implemented image segmentation using a suitable segmentation model.
7. Visualized and analyzed the results.

## Results

The YOLO object detection model ran successfully and generated evaluation results. Detected object classes included person, dog, horse, elephant, umbrella, and potted plant.

Detection results were saved in the Google Colab directory:

`/content/runs/detect/val`

## How to Run

1. Open the notebook in Google Colab.
2. Run the cells sequentially.
3. Install the required libraries when prompted.
4. Execute the object detection and segmentation implementations.
5. View the generated results.

## Conclusion

This task demonstrates the application of deep learning in computer vision. Object detection identifies and locates objects in images, while image segmentation identifies the regions or pixels belonging to objects.
